# PersonaMate AI · 答辩演示脚本与 PPT 大纲

## 一、PPT 大纲（15 页）

1. **封面**：PersonaMate AI — 个性化多模态 AI 伴侣与社交对话平台
2. **痛点与选题**：孤独感加剧 × AI 千篇一律 × 隐私焦虑 → 我们做「懂你、陪你、护你」的 AI
3. **核心卖点**（4 象限）：情绪自适应界面 / 长期个人记忆 / AI 伴侣+真实社交 / 用户自带 AI 接口
4. **系统架构**：Next.js 全栈 + LangGraph Agent + RAG + MCP + Socket.io + 统一模型网关
5. **亮点 1：统一对话中枢**：AI 伴侣 / 好友 / 群聊同系统，右侧按类型切换能力
6. **亮点 2：情绪自适应界面**：7 情绪 × 主题色/壁纸/音乐/字体/动效联动，2s 平滑过渡
7. **亮点 3：Agent 工作流可视化**：8 节点思考链实时展示，自主决策（关怀模式/引用记忆/人工复核）
8. **亮点 4：RAG 个人记忆**：BM25+向量+RRF+重排，引用溯源，无/有 RAG 效果对比
9. **亮点 5：多模态与音乐壁纸联动**：Whisper/OCR/TTS/SD + 网易云 + Three.js 音乐响应壁纸
10. **亮点 6：用户自带 AI 接口**：9 服务商统一网关，AES-256-GCM 加密，失败自动降级
11. **AI 安全与隐私**：Guardrails、PII 四策略、风险评分可解释、人在回路、AIGC 标识
12. **MCP 自建生态**：14 工具 + 全量审计 + 调用时间线
13. **工程质量**：TS 严格模式、组件分层、react-virtuoso、SSE、错误边界、骨架屏、性能优化
14. **社会价值与商业潜力**：缓解孤独 / AI 社交辅助 / 订阅 + 用户自带 Key 降本
15. **演示与 Q&A**：现场 Demo

## 二、现场演示脚本（8 分钟）

| 步骤 | 操作 | 展示点 |
|------|------|--------|
| 1 | 打开主页 | 动态壁纸 + 玻璃质感卡片 + framer-motion 入场动画 |
| 2 | 点击日夜间切换（亮色→暗色→跟随系统） | 玻璃质感实时变化，300ms 不闪屏 |
| 3 | 设置 → AI 接口 → 填 DeepSeek Key → 测试连接 | 显示延迟；Key 掩码展示，强调 AES 加密 |
| 4 | 回主页对话，输入「今天有点累」 | SSE 流式输出 + Agent 思考链逐节点点亮；识别 sad → 界面平滑过渡深蓝、壁纸淡入雨滴、音乐切钢琴；展示推荐理由 |
| 5 | 对话中枢左侧 | AI 伴侣 + 好友 + 群聊三类会话 |
| 6 | 点好友对话 | 实时消息、在线状态、输入中；点「总结对话」「建议回复」展示 AI 辅助（3 种风格） |
| 7 | 进群聊，输入「@AI 今天讨论了什么」 | AI 被唤醒；展示自动总结、情绪感知 |
| 8 | 记忆库搜索「上次提到的」 | 展示 RAG 检索结果、相关度、引用溯源 |
| 9 | 成长报告 | Recharts 情感曲线、统计卡片 |
| 10 | 隐私设置 | 强调 AI 辅助需主动触发、不偷看私信、数据可导出删除 |
